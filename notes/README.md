# 강의 노트

강의를 공부한 뒤 내 말로 정리한 노트를 `notes/<강의 id>.md` 로 둡니다(예: `notes/kalman-filter.md`). 강의 id 는
`lessons/` 의 폴더 이름입니다. 형식은 [docs/templates/note.md](../docs/templates/note.md) 를 복사해서 씁니다.

- 노트가 있는 강의는 지도에서 원 오른쪽 위에 점이 붙고, 강의 창의 **내 노트** 탭에서 열립니다
- GitHub 를 연결한 사이트에서는 **내 노트** 탭에서 바로 쓰고 저장하면 이 폴더에 커밋됩니다(휴대폰에서도 됩니다)
- 이미지는 `notes/img/` 같은 하위 폴더에 두고 상대 경로로 겁니다
- 다른 강의로 가는 링크는 `../lessons/<강의 id>/README.md` 로 쓰면 사이트 안에서 그 강의가 열립니다
- 노트는 직접 씁니다. AI 에게 맡기면 증거가 되지 못하고, 면접에서 그 내용을 물었을 때 답할 수 없습니다
